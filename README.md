# 1. Student Marks Analysis

## Description

This project is a simple student marks analysis program created using Python. It uses the Pandas library to organize and analyze the marks of different students. The program finds the highest marks, lowest marks, and average marks. It also sorts the data and displays it in a bar graph using Matplotlib. This project helped me understand the basics of data analysis and data visualization.

### Features
- Create a student dataset
- Display student information
- Find highest, lowest, and average marks
- Sort student records
- Display a bar graph

### Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

# 5. Employee Salary Data Analyzer

## Description

This project is a simple employee salary data analysis system created using Python. It uses the Pandas library to organize and analyze employee information such as name, department, age, and salary. The project calculates useful statistics like the highest salary, lowest salary, and average salary. It also allows filtering employees by department and sorting the data based on salary. To make the results easy to understand, the project uses Matplotlib to create bar charts and pie charts. This project helped me understand the basics of data analysis, data visualization, and working with datasets in Python. It is a beginner-friendly project that demonstrates the skills I learned during my AI Bootcamp.

### Features
- Analyze employee data
- Calculate salary statistics
- Filter employees by department
- Sort salary records
- Create bar chart
- Create pie chart

### Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
